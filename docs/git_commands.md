# Git Commands

Run these commands from the parent folder that contains `COMP8851-English-Bangla-BackTranslation`.

```bash
cd COMP8851-English-Bangla-BackTranslation
git init
git add .
git commit -m "Initial research repository for English-Bangla back-translation project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/COMP8851-English-Bangla-BackTranslation.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username before running the remote command.
